## Findings

### Critical

**C1. The office window crashes at start-up because the Project Manager has no character drawing.** Confidence: confirmed (traced line by line; not run in a browser).
- Where: `docs/agents/visual-office/index.html` line 862 adds `{id:'project-manager', ...}` to `AGENTS`, but the character table `CH` (starts line 1018) and the pixel table `PXD` have no `project-manager` entry.
- Trigger: opening the office page in any mode. Line 2759 runs `buildChart()`, which calls `makeCard(a.id)` for every entry of `AGENTS` (line 2007). `makeCard` calls `charSVG(id)` (line 1956), which calls `monkeySVG(id)`; line 1198 is `var c=CH[id],o=c.o||{}`, and `CH['project-manager']` is undefined, so it throws a TypeError. The rest of line 2759 and everything after it do not run: `buildLegend()`, `resetView()`, theme and layout set-up, and `startSource(); loadRoster()` (line 2772). The live window never reads events.
- Why it matters: the office window is the owner's live view of the team; with this entry it is blank or half-drawn and never shows any agent's work. The pytest suite does not run the page script, so it stays green.
- Smallest fix: add `'project-manager'` entries to `CH`, `PXD`, `PROPS` and `DESK` (copy the shape of an existing seat such as `pba`, with its own colours and props). Add a small check (for example in `tests/test_install_office.py`) that every `AGENTS` id has a `CH` and `PXD` key, so the next new seat cannot do this again.
- Who: the boss, or whichever engineer maintains the office page.
