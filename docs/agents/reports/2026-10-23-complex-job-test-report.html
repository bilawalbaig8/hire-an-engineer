Natija: kya mila

Architect

Maujooda structure samjha, aur coupons aur card payment ka design likha. 5 decision records: coupon ke paison ke qaide, card entry payment company ke apne page par, callback ki verification, data ka format, aur provider-neutral interface.

Aap ke jawabon ke baad sab 5 ADR accepted hue, aur chhote faislon (kam se kam amount ka coupon hatana, coupon sirf admin banaye) ko "architect ka andaza" likha gaya.

Code Reviewer

review/tests: fixes ke baad merge qeemat minus ho sakti hai, coupon order me lagta hi nahi, tests kuch check nahi karte.

review/security: merge mat karo admin delete ka check nahi, search se SQL injection, search sab ke orders dikhati hai, code me key likhi hai.

Dusre review me ginti: tests branch 0 Critical / 4 Important / 2 Minor, security branch 3 Critical / 2 Important / 1 Minor.
