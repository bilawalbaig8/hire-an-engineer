# Example reference

Replace this file with real reference files, one topic each. Every reference has the same shape so the router in `SKILL.md` can point at it:

1. **When to read this**: one line.
2. **The decisions that matter**: each as "choose X when ..., otherwise Y", and what is given up.
3. **Typical shapes and failure modes.**
4. **Checks before finishing.**
5. **Sources**: IDs only, such as `[S-AREA-1]`, each one present in `sources.md`.

Write in your own words. Ideas from books and papers are summarised and cited, never copied.
