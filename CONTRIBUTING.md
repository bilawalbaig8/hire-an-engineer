# Contributing

Thank you for helping improve these skills.

## How you can help
- **Report gaps, bugs or wrong behaviour** with the issue forms: what you asked, what the agent did, what you expected, which tool.
- **Suggest improvements or new skills** with the feature or new-skill forms.
- **Share results**: if a skill worked well (or badly) on a real project, describe it in an issue — without private details.

## What we don't accept
- Pull requests. The owner makes all changes, often prompted by your issues.
- Issues containing private code, credentials, API keys, customer data or personal information. Such issues will be deleted.
